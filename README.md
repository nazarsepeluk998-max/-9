# Call of Duty Modern Warfare 4

На Корейському півострові спалахує війна, коли Північна Корея розпочинає повномасштабне вторгнення, яке загрожує дестабілізувати світ. Молодий загін південнокорейських солдатів бореться за виживання на передовій, що руйнується, тоді як за півсвіту мстивий капітан Прайс веде особисту війну з тіні, залишаючись на крок попереду тих, хто за ним полює.
